# 初三全科 AI 学习助手（网页版 MVP）设计文档

- 日期：2026-08-15
- 状态：已确认，待进入实现计划

## 1. 产品定位

一个"会鼓励你的学霸 AI 同桌"，帮助初三学生全科（语数英物化政史）答疑、讲题、刷题、查漏补缺，用游戏化和即时反馈让孩子愿意每天主动使用，目标指向中考提分。

核心气质（四位一体，缺一不可）：
- **游戏化**：积分 / 等级 / 徽章 / 连续打卡天数
- **AI 陪伴**：固定人格的鼓励型 AI 角色
- **即时正反馈**：每步都看见进步
- **轻量不压迫**：无硬性作业、孩子自主节奏

## 2. 核心使用闭环

每天 15–25 分钟：

```
选择科目 / 中考考点
  → AI 出小题 或 孩子拍照/打字提问
  → AI 引导式讲解（先问思路、再点破、最后总结）
  → 做对得积分 / 升级
  → 错题自动进错题本
  → 薄弱点推送专题
```

设计原则：轻量不压迫、游戏化、AI 陪伴、即时正反馈贯穿全流程。

## 3. 功能模块（MVP 范围）

1. **AI 答疑讲解**：孩子输入题目/问题，AI 用"引导式讲解"（先问思路、再点破、最后总结），语气像朋友。
2. **智能刷题**：按科目 / 中考考点出题，难度自适应（做对变难、做错降难度）。
3. **错题本 + 薄弱点分析**：自动归集错题，按知识点统计"红绿灯"（红=薄弱，绿=掌握）。
4. **游戏化系统**：积分、等级、连续打卡天数、徽章（如"数学小能手"）、周排行榜（默认可关闭，避免焦虑）。
5. **AI 陪伴角色**：固定人格（暂定"阿杰学长"），会鼓励、会记住孩子的进步，减少抵触。
6. **进度可视化**：首页仪表盘显示"已掌握考点 X/Y""距离目标校还差多少分"等。

## 4. 技术架构（网页版 MVP）

- **前端**：纯网页（HTML/CSS/JS 或轻量框架如 React/Vue），手机 / 平板 / 电脑浏览器均可访问。
- **后端**：轻量服务（Node 或 Python），负责调用 DeepSeek API、用户数据存储、积分 / 错题逻辑。
- **AI**：DeepSeek API（答疑、出题、批改、薄弱点分析，配合精心设计的 prompt）。
- **数据**：用户账号、做题记录、错题、积分——先用最简单存储（如 SQLite / JSON），不过度设计。
- **家长视角**：MVP 后可选，家长可见学习时长 / 进步，但不干涉孩子界面。

## 5. 防反感关键设计（重点）

- 不布置作业、不弹窗催促，全靠"想玩 / 想问"驱动。
- AI 永远先鼓励再指正，错了也说"这步思路很棒，只是这里差一点"。
- 排行榜默认可关，保护后进孩子的自尊。
- 每次打开都有"今日推荐 1 个轻松小挑战"，降低启动门槛。

## 6. 后续扩展路线

网页版 MVP 验证意愿度和提分效果 → 微信小程序（随时用、家长监督）→ 原生 App → 加拍照识题 / 语音。

## 7. 成功标准（待实现时细化）

- 孩子愿意每天主动打开（留存 / 打卡天数）
- 使用中考点掌握度上升（红绿灯变绿比例）
- 阶段性测试 / 模拟考成绩提升
